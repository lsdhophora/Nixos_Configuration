# 文本图·表 绘制技能（CJK 全角对齐 · CLI 校验）

## 核心规则

1. **对齐靠 CLI，禁止手工计算**。不逐字数空格、不算宽度、不目视对齐。草稿只保证内容正确，宽度交给工具。
2. 输出必须用代码块（```` ``` ````）包裹，代码块内不混入 Markdown 装饰（`**`、`_` 等）。
3. 工具输出即最终稿：**原样粘贴，不得手工改动**。若工具未在 PATH，提示用户先执行 `nixos-rebuild switch --flake /home/lophophora/.config/nixos#flowerpot`，不要手工对齐。

## 工作流（必须按顺序）

1. **定内容**：确定列、行、数据、嵌套关系（宽度随意）
2. **选样式**：按内容类型选草稿样式（见下表）
3. **起草稿**：写粗略版本，内容准确即可
4. **跑 CLI**：运行下方工具命令
5. **誊清**：把工具输出原样粘贴进代码块

## 样式选择

| 内容类型 | 草稿样式 | CLI 工具 |
|---|---|---|
| 数据表格（含全角表头） | Markdown 表格语法 `\| 列 \| 值 \|` | ascii-align |
| 盒图 / 屏幕布局 / 分层架构图 | Unicode 框线 `┌ ─ ┐ │ └ ┘ ├ ┤ ┬ ┴ ┼` | ascii-box-aligner |
| 简单盒子（无内部分栏） | ASCII `+ - \|` 或 Unicode 框线 | ascii-align |
| 流程图（盒子 + 箭头） | Unicode 框线 + ASCII 箭头 | ascii-box-aligner |

## 工具命令

### ascii-align（表格 / 简单盒子）
```bash
ascii-align check draft.txt        # 检查对齐；未对齐时退出码 1（已对齐为 0）
ascii-align fix draft.txt --stdout # 修复并输出到 stdout —— 粘贴此输出
```

### ascii-box-aligner（盒图 / 布局）
```bash
cat draft.md | ascii-box-aligner - # 草稿用 ``` 围栏包裹；结果到 stdout —— 粘贴此输出
```

## 样式规范（工具可正确解析的前提）

### 表格（ascii-align）
- Markdown 表格语法：表头行 + 分隔行 `|---|---|`，数据行跟上
- 分隔行控制对齐方向：`:---` 左对齐、`:---:` 居中、`---:` 右对齐
- 内容含 `|` 时用 `\|` 转义

### 盒图（ascii-box-aligner）
- 用 Unicode 框线；盒子必须闭合（有顶角、底角）
- **顶部边框必须是一整行 `┌────┐`**，禁止按列分段写 `┌──┬──┐`（工具会误判为单盒）
- **带列结构的盒子必须加表头分隔行 `├───┼───┤`**，否则列结构丢失（见下方反例）

### 禁止
- 表情符号、全角空格（宽度环境依赖/不可见）
- 制表符缩进（只用空格）

## 常见错误与对策

| 现象 | 原因 | 对策 |
|---|---|---|
| 全角列右移 / 边框不齐 | 手工计算宽度 | 禁止手工算，跑 CLI |
| 表格型盒子列结构丢失 | 缺表头分隔行 | 加 `├───┼───┤` 行后重跑 |
| 工具不识别盒子 | 边框不闭合 | 补齐顶/底角后重跑 |
| 混合字符集错乱 | `+` 与 `┌` 混用 | 统一字符集后重跑 |

## 输出前检查清单

- [ ] 图/表是否跑过 CLI（`ascii-align fix` 或 `ascii-box-aligner`）？
- [ ] 粘贴的是工具输出原文，未手工改动？
- [ ] 代码块内无 Markdown 装饰、无全角空格、无表情符号？
- [ ] 表格型盒子是否带表头分隔行？

## 正确示例（CLI 实测输出）

### 表格：草稿 → `ascii-align fix`

草稿（内容正确，宽度不齐）：

```
| 项目 | 值 |
|------|----|
| 名称 | Alice |
| 地址 | 东京 |
```

CLI 输出（粘贴此版本；`ascii-align check` 对其返回 0）：

```
| 项目 | 值    |
|------|-------|
| 名称 | Alice |
| 地址 | 东京  |
```

### 盒图：草稿 → `ascii-box-aligner`

草稿（带表头分隔行，宽度不齐）：

```
┌─────────────────────────────┐
│ 组件        │ 职责          │
├─────────────┼───────────────┤
│ 人层        │ 审批与决策    │
│ LLM 层     │ 信息检测       │
│ 策略层      │ 确定性风控     │
└─────────────┴───────────────┘
```

CLI 输出（粘贴此版本）：

```
┌─────────────────────────────┐
│ 组件        │ 职责          │
├─────────────┼───────────────┤
│ 人层        │ 审批与决策    │
│ LLM 层     │ 信息检测       │
│ 策略层      │ 确定性风控    │
└─────────────┴───────────────┘
```

### 反例：无表头分隔行的表格型盒子（工具输出会破坏列结构）

草稿（错误）：

```
┌───────────────┬──────────────┐
│ 人层          │ 决策权       │
│ LLM 层       │ 信息检测      │
│ 策略层        │ 确定性风控    │
└───────────────┴──────────────┘
```

`ascii-box-aligner` 输出（列结构丢失，不可用）：

```
┌───────────────┐
│ 人层          │ 决策权       │
│ LLM 层        │ 信息检测      │
│ 策略层        │ 确定性风控    │
└───────────────┘
```

对策：中间补一行 `├───────────────┼──────────────┤` 表头分隔行后重跑。
